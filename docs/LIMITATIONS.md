# 使用限制

- 固定身份是经营者配置的角色关系与称呼，不是实名认证。QQ 按 Host 消息作者匹配，不根据群昵称或聊天自称认定。
- 名单只影响聊天表达，不授予管理员权限。名单外和对象未知分别处理；无法确定对象时不猜测最近发言者。
- 本插件不修改宿主消息记录、群名片或长期记忆。模型仍可能受其他上下文影响，提示正确不等于真实回复绝不误认。
- 模型提示只包含当前适用的称呼和相处说明；不广播整份名单，也不在公开查询中提供名单。
- 同一 QQ 的群专属配置优先于全局配置，重复范围会被拒绝；停用群专属条目后仍可能匹配全局条目。
- Planner 当前只收到一般来源规则，不承诺为多人对话选出一个固定身份对象。
- 个人说明过长时截短说明，保留身份与来源规则。默认不自动增加模型调用。
- 不提供用户登记、用户关系管理或通用跨插件执行令牌。Hush 需要选择 identity 管理员来源才会使用此名单。
- 群消息回执经过正常发送链，睡眠或静音时可能被拦截。

使用方法见 [README](../README.md)，开发接口见 [API](API.md)。
