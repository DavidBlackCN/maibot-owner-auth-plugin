# 备份与恢复

停止插件及依赖其权限查询的管理操作后，保存同一时点的插件代码、安装目录的 `config.toml` 和 SDK 数据目录中的完整插件数据。不要在数据库仍被使用时直接复制它。

恢复时使用配套的代码、配置和数据，并保留恢复前的数据副本。先检查插件加载、固定身份匹配及管理员权限，再恢复业务。禁止新旧实例同时使用同一数据目录；写锁报错时先检查是否仍有实例运行，不删除锁文件强行启动。

插件仅使用 `identity.db` 的内部上下文标识；身份名单与管理员名单来自配置。遇到损坏或不认识的数据库格式会停止加载，不清库重建。已有其他记录不会自动删除。

Vita、Coordinate 等执行插件的操作回执和未知结果由它们各自管理。恢复 Identity 不能撤销已经发生的动作，也不能据此重发结果未知的操作。
